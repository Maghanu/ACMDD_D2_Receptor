# Dopamine D2 Receptor (D2R) Ligand and Interaction Analysis

This repository contains a Python workflow for analyzing Dopamine D2 receptor (D2R) ligands and receptor-ligand interactions using public data from ChEMBL and PDB.

The project focuses on:
- retrieving binding activities for the D2 receptor target
- summarizing ligand properties and action types
- identifying common scaffolds and physicochemical patterns
- mapping PDB structures to receptor interaction residues and ligand classes
- linking PDB ligands back to ChEMBL compounds and potency annotations

## Project goal

The main workflow is implemented in `CHEMBL_DRUG_D2.py` and is designed around the D2 receptor target:
- ChEMBL target: `CHEMBL217`
- UniProt accession: `P14416`

It combines two major analyses:
1. ChEMBL-based property and potency analysis
2. PDB-structure interaction analysis for D2 receptor complexes

## Repository contents

- `CHEMBL_DRUG_D2.py` — main analysis script
- `DOWNLOAD-...csv` — downloaded dataset related to the project

- `Test` — project test or scratch artifact file

## Dependencies

The script requires Python packages including:

```bash
pip install chembl_webresource_client rdkit pandas numpy matplotlib requests plip
```

For PLIP, Open Babel may also be required:

```bash
conda install -c conda-forge openbabel
```

## Usage

From the repository root, run:

```bash
python CHEMBL_DRUG_D2.py
```

This script will:
- fetch activity data from ChEMBL
- compute compound-level summaries
- write CSV files to `d2_analysis/`
- generate overview plots
- query D2-related structures from PDB
- analyze residue interactions using PLIP
- link PDB ligands to ChEMBL records and action classes

## Outputs

The script writes results into the `d2_analysis/` folder, including:

- `chembl_activities_raw.csv`
- `chembl_compounds.csv`
- `chembl_summary_by_action.csv`
- `chembl_top_scaffolds.csv`
- `chembl_overview.png`
- `pdb_interactions.csv`
- `pdb_interaction_frequency.csv`
- `pdb_contact_map.png`

## Analysis workflow

### ChEMBL section
The script:
- filters for binding assay data with `Ki`, `Kd`, or `IC50`
- keeps only compounds with valid SMILES and pChEMBL values
- groups compounds by molecule and calculates median potency
- computes ligand descriptors such as molecular weight, logP, TPSA, H-bond counts, rotatable bonds, and scaffold information
- summarizes activity by action type (agonist, antagonist, etc.) when annotated

### PDB interaction section
The script:
- identifies PDB entries associated with D2 receptor (UniProt `P14416`)
- downloads relevant structures
- analyzes interactions with PLIP
- filters non-drug hetero groups such as solvents and ions
- maps receptor residues to Ballesteros-Weinstein numbering where available
- links ligands to ChEMBL compounds and associated action types
- outputs residue interaction frequency tables and a ligand-residue contact map

## Notes

- This analysis depends on live access to ChEMBL, RCSB, and GPCRdb services.
- Execution time may be several minutes because it downloads and analyzes multiple structures.
- The repository is intended for research / exploratory computational chemistry workflows rather than a packaged production application.
