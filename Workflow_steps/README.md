# Historical workflow materials

This directory preserves notebooks and scripts from earlier project
iterations. It is retained for provenance and comparison, not as the
authoritative current pipeline.

The active workflow is organized in `../src/` and uses experimentally
measured DRD2 compounds and activity endpoints to generate fingerprints and
evaluate ligand-based models. See the repository root README for the current
execution sequence.

When reusing historical analyses, check their input datasets, activity
definitions, preprocessing, model splits, and output paths before comparing
them with current results. Keep ML predictions, docking scores, and
experimentally measured values clearly distinguished.
